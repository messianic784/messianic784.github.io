Privacy Policy

EpicEchoes

Last updated: July 29, 2026

EpicEchoes is an independent, single-operator content project that publishes short-form videos (facts, stories, and similar clips) to platforms including YouTube, TikTok, and Facebook. This policy explains what data our software touches when it connects to those platforms' APIs, and — just as important — what it does not collect.

01 What this software does

EpicEchoes uses each platform's official developer API strictly to publish video content to its own accounts — setting a title, description, tags, and privacy status on uploads. It does not browse, message, follow, or interact with other users, and it does not read anyone else's content.

02 Information we do not collect

We do not collect, store, or process personal data belonging to viewers, followers, or any third party. There is no login system, no user accounts, no analytics tracking of visitors, and no advertising identifiers on our side.

03 What is stored, and where

The only credentials involved are API access tokens issued directly by each platform, authorizing our software to publish on the operator's own account. These tokens are stored locally on the operator's own device and are never shared, sold, or transmitted to any other party.

In plain terms

If you're not the person running EpicEchoes, this software has no way to see, store, or act on anything of yours.

04 Third-party services used

Generating and publishing each video involves the following services, each governed by its own privacy policy:

YouTube Data API

Publishing videos to our channel

TikTok Content Posting API

Publishing videos to our account

Meta Graph API

Publishing videos to our Facebook Page

Google Gemini API

Generating video scripts

Pexels API

Sourcing licensed stock footage

None of these integrations involve sharing viewer or third-party personal data — only content we generate ourselves is sent through them.

05 Children's privacy

EpicEchoes does not knowingly collect information from anyone, including children, because it does not collect personal information from its audience at all.

06 Changes to this policy

If this policy changes, the "last updated" date above will change with it. Continued use of any EpicEchoes account after an update means the current version applies.
